# GitHub CLI（gh）

- GitHub の操作には `gh` コマンドを使用すること
- ユーザーが `/implement-spec` を呼び出した場合は、そのスキルに定める条件とタイミングでdraft PRを作成し、完了後にready for reviewへ変更してよい。この許可は他のPR作成フローやPRのmerge、デプロイの許可を含まない
- `gh repo create` によるリポジトリ作成は禁止。必要な場合はコマンド案を提示するにとどめる
